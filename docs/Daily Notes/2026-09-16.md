# 2026-09-16

## Live-instance outage: missing `email-validator` dependency

Owner reported the personal instance (`thebaileys.logcoretech.com`) was down with a 502 after a power loss — the box rebooted without internet, and relaunching once connectivity was back made it worse, not better.

**Diagnosis**: `docker ps -a` showed `logcore-app` crash-looping (`restartCount=20`, health never passing). `docker logs logcore-app` showed a clean `ImportError: email-validator is not installed` during `main.py`'s router import chain (`routers/auth.py`'s `RegisterRequest`/`LoginRequest`/admin `CreateUserRequest` all use `pydantic.EmailStr`, which needs that package). `email-validator` was never in `app/backend/requirements.txt` or `uv.lock` — not part of this session's uncommitted changes, not in any prior committed version either. The previously-running image must have had it some other way (stale cached layer, manual install at some point); the relaunch forced a real `docker compose build`, which installs strictly from `requirements.txt` and had nothing to fall back on. `logcore-tunnel`'s logs confirmed the 502 was purely "nothing answered at `localhost:8000`" — no proxy/DNS/tunnel issue at all.

**Fix**: added `email-validator==2.2.0` to `requirements.txt`, rebuilt `docker-app`, recreated the container. Confirmed healthy: clean startup log, `/api/v1/health` → 200, public domain → 200, tunnel error log quiet since the fix.

Full writeup + prevention notes: `docs/MEMORY.md`'s 2026-09-16 Known Gotchas entry. CHANGELOG.md got a `### Fixed` entry under `[Unreleased]`.
