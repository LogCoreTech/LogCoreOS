## Dashboard QA pass on the 2026-08-05/07 grid/picker round — two real bugs found and fixed

Owner asked for a live verification pass on the "real pickers + finer grid" work: 36-col/24px-row grid,
real search pickers instead of raw-id text boxes, the ✎ edit button, drag/resize behavior. Ran it against
an isolated backend + synthetic brain (never the real household instance) via Playwright — all 5
requested behaviors confirmed working end to end, including the drag/resize rest-position check that a
prior round had flagged as "not cleanly confirmed live" (two of my own test-script bugs along the way,
not product bugs: a stale login-rate-limit assumption, and a `text=` locator tripped up by a
CSS-`uppercase` label — fixed in the script, not the app).

Two real, previously-unreported bugs turned up and were fixed in `Dashboard.jsx` (owner: "fix all the
issues you found," "no migration needed, just fix it" — a small number of already-corrupted blocks on
real data were left alone since they still render fine):

- **Saving a block silently exited Edit mode** — `loadCurrent()` unconditionally reset `editing` to
  `false`, and every add/edit/remove block call refreshed state through it. Fixed with an opt-out
  `resetEditing` param, `true` only for a genuine dashboard switch.
- **New blocks' bottom-stacked layout used `y: Infinity`**, which `JSON.stringify` silently turns into
  `null` over the wire — confirmed present on real data (3 blocks in one real user's `dashboards.json`).
  Fixed with a real computed integer (`nextY()`).

Full writeup + the exact mechanism: `docs/MEMORY.md` Known Gotchas (both entries, 2026-08-09).

## AI Chat/Agent expansion — replay-bug fix unified with 4 more capabilities into one mechanism

Owner asked me to re-surface an earlier research round (MCP, memory, Skills, sub-agents, background
tasks, onboarding, nudges, rich previews — logged for a future round the first time it came up) and
pick which to pull into the active plan now. Answer: everything except MCP (explicitly kept out — an

3. *(skipped this round — chat-session-persistence; depends on nothing else, deferred)*
4. **AI agent tools for Dashboards** — full CRUD + templates, approval-gated, now reliably replayed.
5. *(skipped — memory/skills/sub-agents/background-tasks/onboarding/nudges; independent, deferred)*
9. **`propose_plan` migrated onto the same mechanism** — same shape of bug, never reported until this
   review surfaced it.
12. **In-chat rich preview** for `add_dashboard_block`/`update_dashboard_block` approvals — reuses the
    real `DashboardGrid`/`BlockRenderer` in read-only mode instead of a plain bullet list.
